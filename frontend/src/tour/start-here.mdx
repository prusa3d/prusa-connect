# Start here

This Storybook shows the whole Prusa Connect product. It draws the real app over recorded answers, so no server is needed.

## What the sidebar holds

- **Tour** walks through the product in the order a person meets it. Each page uses one fleet size.
- **Screens** has every screen in all its states. These states are populated, empty, loading, failed and refused.
- The other groups hold the parts the screens are built from.

## The switch in the toolbar

**Theme** switches between light and dark. It applies to every story.

## Where to go next

Open **Tour / One printer** for a small desk. Open **Tour / A farm** to see how the same screens look with many printers.
