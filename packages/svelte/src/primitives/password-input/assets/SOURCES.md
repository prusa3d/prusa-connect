# Password visibility icons

Source: [PrusaSlicer icon board](https://www.figma.com/design/2LBnrP7Xkbj1hxpTOMYSJM/PrusaSlicer?node-id=6779-17870).
Both SVG files are unchanged 16 by 16 exports.

| File                 | Figma node            | Use                                    |
| -------------------- | --------------------- | -------------------------------------- |
| password-visible.svg | 3958:31022, Icon=Hide | Open eye on the Show password action   |
| password-hidden.svg  | 4366:26836, Icon=Show | Closed eye on the Hide password action |

The table records the source names and their use in this component.
The button label names the action.
Dark mode uses the original light artwork. Light mode inverts the rendered
image so the same glyph remains visible on a light field.
