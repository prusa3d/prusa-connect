3MF projects shows what a `.3mf` project file holds. A 3MF file is a zip archive with the models, how they stand on the beds and the slicer's settings. PrusaSlicer, OrcaSlicer and BambuStudio save their projects in it.

With the extension switched on, the page of a `.3mf` file in a storage shows the project. It shows the printer setups, each bed with the slicer's picture and a plan, the objects with every copy of them, and the settings. A listing shows the project's picture, and the file's page lists its title, its printer and its objects.

Without it, the server still shows the picture a project carries in a listing, and reads nothing else of the file.

Nothing needs to be set up. The extension reads files as the person who opens them, so a person sees only the projects in storages they may read. A project is read whole, so the first look at a very large project can take a while. The extension keeps the answer in memory, and the next look is quick.

Other extensions can build on this one in two ways. A Go module imports the reader, the package `github.com/prusa3d/threemf/threemf`. A browser bundle draws the project view, the component `project-view`, on a page of its own. It can then act on the copies a person ticks there, for example to print or slice them. The README in `extensions/threemf` describes both, with the limits and the error codes of the routes.

## What it adds {#what-it-adds}

- **Project**: a view of what a file holds, on the file's page, for `.3mf`
- **`project-view`**: a component other modules may draw on their own pages
- the server asks it to describe a file of type `.3mf`: the picture in a listing and the details on the file's page

## What it needs {#what-it-needs}

- a server release `>=0.0.1-alpha.7`
- the server methods `storage.fetch`, `storage.stat`

It asks for no permission of its own. It acts only for the person who asks.

## Routes {#routes}

Every path is under `/api/v1/modules/com.github.aux.prusa3d.threemf`. The extension's `openapi.json` describes each of them, and the server serves it at `openapi.json` under the same path.

| method and path | what it does |
|---|---|
| `GET /project` | What one 3MF project holds. |
| `GET /project/mesh` | One object of a 3MF project as triangles. |
| `GET /project/thumbnail` | One picture of a 3MF project. |
