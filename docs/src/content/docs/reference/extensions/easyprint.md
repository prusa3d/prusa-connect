EasyPrint is the Prusa slicer that runs in a browser, on the Printables site. It sends a print to your server from the browser of the person who uses it. This extension lets it: the server answers EasyPrint's page while the extension is switched on, and the extension's tab has the link that adds your server to EasyPrint.

It is a browser bundle only. The server checks it against its digest and serves it, and never runs it.

## Allow EasyPrint to call the server {#allow}

EasyPrint's requests come from the origin `https://slicer.printables.com`. A browser lets that page read the server's answer only when the server names the origin. The extension asks for it, and the install dialog shows the request:

> Pages of https://slicer.printables.com may call this server from a browser, with the rights of the person who opens them, while the extension is switched on.

An administrator approves it with the install. The origin then shows under Settings, Server, Network, in **Pages that may call this server**, with the extension's name. Switch the extension off or remove it, and the server stops answering EasyPrint at once. Nothing is written into `core.api.allowed_origins`.

The extension gives EasyPrint no credential. EasyPrint asks for one, and a person approves it the way [Pair an app](../../scoped-credentials-and-app-pairing.md#pairing) describes.

## Add the server to EasyPrint {#add}

Open the web app on the address EasyPrint should call. Open **Settings**, then **Extensions**, then **EasyPrint**, and choose **Add this server to EasyPrint** on the EasyPrint tab. A new tab opens `https://www.printables.com/slice` with the address from your browser's address bar in the `pair_connect_local` parameter. EasyPrint opens its form for a new server with that address filled in.

The address is the one your browser reached the server on, because EasyPrint calls the server from the same browser. A server you opened as `http://192.168.1.10:8080` is added under that address.

## HTTPS or plain HTTP {#https}

EasyPrint is an HTTPS page. Every browser lets it call a server that answers over HTTPS with a certificate the browser trusts. To serve the API that way, set `core.api.tls.certificate` and `core.api.tls.key`, which [Configure the core](../../certificates.md#configure-the-core) lists, or put a reverse proxy that holds the certificate in front of the server.

A server on plain HTTP works in fewer browsers, and only on an address of the local network. Chrome asks the person for permission to reach devices on the local network, and then lets EasyPrint call the server. Another browser may refuse the call, so HTTPS is the choice that works everywhere. The EasyPrint tab warns when the page is open over plain HTTP.
