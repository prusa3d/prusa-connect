Parts keeps a private catalogue of parts on one server, like a small Printables that nobody outside the server sees. A person makes folders and puts parts in them. A part has a name, a summary, a description, tags and comments, and its files are kept as versions, each with a note on what changed. A print file of a version is printed from the part's page, on a printer the person picks. Two dashboard cards show the newest parts of a folder, or parts a person chose.

Before you switch it on, decide two things:

- **Where the files go.** The files are uploaded to one of the server's storages, `local` by default, under the folder `parts`. The settings below change both. A storage takes only the file types its `allowed_extensions` list names, so a catalogue that keeps drawings or documents needs a storage of its own with an empty list.
- **Where the catalogue goes.** The folders, parts, versions and comments live in a database of the extension's own. The install dialog asks for it: a SQLite file in the extension's data directory, which is the default, or a Postgres database.

The server decides every request before the extension sees it. Reading the catalogue takes `view_resource` on the extension, changing it takes `operate_resource`, and a file takes `read_storage` or `write_storage` on its storage. Only the author of a comment may change or delete it.

The README in `extensions/parts` lists the limits, the error codes and what happens on an upgrade from 0.2.

## What it adds {#what-it-adds}

- **Parts**: a page of its own, with an entry in the sidebar
- **Parts folder**: a card a person can place on a dashboard
- **Chosen parts**: a card a person can place on a dashboard

## What it needs {#what-it-needs}

- a server release `>=0.0.1-alpha.7`
- the server methods `storage.stat`
- a database of its own, SQLite or Postgres, chosen at install

It asks for no permission of its own. It acts only for the person who asks.

## Settings {#settings}

An operator writes them under `config:` in the extension's entry of the configuration.

| key | type | default | what it sets |
|---|---|---|---|
| `storage` | string | `local` | The server storage the catalogue's files are uploaded to. |
| `root` | string | `parts` | The folder inside that storage the catalogue's files are kept under. |
