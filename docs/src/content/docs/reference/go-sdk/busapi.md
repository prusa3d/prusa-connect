`busapi` is how a module reads the host's event stream and publishes on it.
`Subscribe` opens one stream and hands the module coalesced windows until the
context ends. `Emit` puts one fact on the bus.

A module names two things when it emits: an endpoint the operator declared in
the instance's configuration, and a payload. The event type and the origin
are the host's, settled before the process was started, and no field on the
wire carries either. That is what stops a module publishing into a namespace
it does not own. A subscription narrows by origins, types and window, and it
carries a principal. That is the one `routes.serve` handed in for a request
the module is serving, or empty for the module's own work. Empty resolves
against the instance's own grants, so a module granted nothing reads nothing.

| you want to | call |
|---|---|
| read every telemetry sample, as the module itself | `Subscribe` with `Types` set and `Principal` empty |
| read for the person whose request you are serving | `Subscribe` with `Principal` from `routesapi.PrincipalOf` |
| come back after a restart without a gap | `Subscribe` with `Resume` set to the last window's `Cursor` |
| publish one fact | `Emit`, or `EmitRaw` with bytes already encoded |

```go
package shelf

import (
	"context"
	"sync/atomic"

	"github.com/prusa3d/prusa-connect/sdk/busapi"
	"github.com/prusa3d/prusa-connect/sdk/event"
	"github.com/prusa3d/prusa-connect/sdk/wirerpc"
)

// countSamples reads telemetry windows as the module itself and adds the
// envelopes in each one to seen, until ctx ends or the host stops writing.
func countSamples(ctx context.Context, conn *wirerpc.Conn, seen *atomic.Int64) error {
	params := busapi.SubscribeParams{Types: []string{event.TypePrinterTelemetrySampled}}

	return busapi.Subscribe(ctx, conn, params, func(window busapi.Window) error {
		seen.Add(int64(len(window.Telemetry)))

		return nil
	})
}

// announce publishes one event on the endpoint the operator declared as
// "changed". The host fills in the type and the origin.
func announce(ctx context.Context, bus *busapi.Client, spool string) error {
	return bus.Emit(ctx, "changed", spool, map[string]any{"spool": spool, "state": "empty"})
}
```

One payload is at most `MaxDataBytes`, 8 KiB. A module with more to say
writes it as a record with [`stateapi`](./stateapi.md) and emits the key. A
window with `Resync` set means continuity is gone: reload state over the API
and carry on from that window's cursor.

## What a subscription sends on the wire

A module written without the Go SDK makes the same call over the
[plugin wire protocol](../../plugin-wire-protocol.md). It opens a stream and
sends `bus.subscribe` on it, with the `SubscribeParams` members below as
params. The host sends no result first. It writes each window on that stream
as one line of JSON, ending in a newline, in `data` frames. A window larger
than one frame, or one written while credit is short, continues in the next
`data` frame. So split the bytes of the stream on newlines, not on frames.
When the host stops writing, it sends an `end` frame and then the answer to
the call, `"result":null`.

| member | type | meaning |
|---|---|---|
| `events` | array of CloudEvents envelopes | the events of the durable classes, in publication order |
| `telemetry` | array of CloudEvents envelopes | the newest value of each telemetry key that changed during the window |
| `resync` | boolean | `true` when continuity is gone |
| `cursor` | string | the place to resume from, sent back as `resume` |

The host omits a member that is empty, so read a missing member as empty or
`false`. One window of telemetry:

```json
{"telemetry":[{"specversion":"1.0","id":"01M10GRRE3XCAEVMWFZHD1RVRF","source":"urn:prusa:site:e2e/device/0c95d38a-4e71-4b06-9f28-73a1c5e04b6f","type":"com.prusa.connect.device.telemetry.sampled","subject":"device:0c95d38a-4e71-4b06-9f28-73a1c5e04b6f","data":{"path":"/state","value":"IDLE"}}],"cursor":"01K2A0S3P4:device/0c95d38a-4e71-4b06-9f28-73a1c5e04b6f=17"}
```
