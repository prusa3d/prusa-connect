`stateapi` is the key/value store a module keeps its own data in, behind a
namespace the host bound before the module ran. Every key in it is the
module's, no other module can read or write one, and a value survives a
restart, an upgrade and the module's own removal. It is the only storage a
module reaches inside the host.

A module builds one `Client` with `NewClient` over its `wirerpc.Conn` and
holds it as `Records`. Six calls over opaque bytes: `Get`, `Put`,
`CompareAndPut`, `Delete`, `List` and `Version`. Nothing on the wire names a
namespace, so reaching another module's records is not a permission a module
lacks but a sentence it cannot write. `Put` is for a value with one writer.
`CompareAndPut` writes only at the version the caller read, and `ErrVersion`
is the ordinary outcome when two instances race: re-read and decide again.
Each call is atomic on its own key and nothing spans two, so a pair that has
to move together goes in one value.

| you want to | call |
|---|---|
| read a value and the version to write against | `Get` |
| write, with one writer | `Put` |
| write only if nobody wrote since you read | `CompareAndPut`, with `AbsentVersion` for a record not there |
| walk one level of a hierarchy | `List` with a prefix ending in `/` |

```go
package shelf

import (
	"context"
	"errors"
	"strconv"

	"github.com/prusa3d/prusa-connect/sdk/stateapi"
)

// bump adds one to the counter under key and answers the version it wrote.
// Two instances racing here both finish: the loser re-reads and writes again.
func bump(ctx context.Context, records stateapi.Records, key stateapi.Key) (uint64, error) {
	for {
		held, err := records.Get(ctx, key)
		if err != nil && !errors.Is(err, stateapi.ErrNoRecord) {
			return 0, err
		}

		// A record that is not there is at AbsentVersion, so the first write
		// only lands if nothing was written in between.
		count, _ := strconv.ParseUint(string(held.Bytes), 10, 64)
		next := []byte(strconv.FormatUint(count+1, 10))

		version, err := records.CompareAndPut(ctx, key, held.Version, next)
		if errors.Is(err, stateapi.ErrVersion) {
			continue
		}

		return version, err
	}
}
```

A call made while the host is still starting the instance answers
`ErrNotReady`; wait a moment and call again. A key is at most 150 bytes, a
value 64 KiB, and a namespace 8 MiB in keys and values together. A larger
thing is a file.

The host serves the store only when the server's configuration declares a
record backend under `resources.db`. Without one, a `state.*` call answers
`-32601`, such as `this side serves no method state.get`. See
[Giving a module more room for its records](../../writing-a-module.md#giving-a-module-more-room-for-its-records).


Package stateapi is the key/value store an extension keeps its own data in.

The host gives each extension a namespace of its own. No other extension can read or write it. A value survives a restart, an upgrade and the removal of the extension.

Each call is atomic on one key. There is no transaction across keys, no query over values and no watch. Use CompareAndPut when a key has more than one writer.

A namespace is limited to DefaultNamespaceBytes unless the operator granted more at install. Values are opaque bytes.

### `Records` {#stateapi-records}

```go
type Records interface {
    // Get returns the record under key, and ErrNoRecord when there is none.
    Get(ctx context.Context, key Key) (Value, error)

    // Put writes value under key, whatever is there, and returns the new
    // version. Use it for a key with one writer.
    Put(ctx context.Context, key Key, value []byte) (uint64, error)

    // CompareAndPut writes value under key only if the record is at expected,
    // and returns the new version. AbsentVersion expects no record. On
    // ErrVersion, read the record again and decide again.
    CompareAndPut(ctx context.Context, key Key, expected uint64, value []byte) (uint64, error)

    // Delete removes the record under key, and returns ErrNoRecord when there
    // is none. A key deleted and written again starts a new version line at 1.
    Delete(ctx context.Context, key Key) error

    // List returns every key under prefix, sorted, without values. The empty
    // prefix lists every key in the namespace.
    List(ctx context.Context, prefix Key) ([]Key, error)

    // Version returns the version of the record under key without reading its
    // bytes, and ErrNoRecord when there is none.
    Version(ctx context.Context, key Key) (uint64, error)

    // Usage returns how much the namespace stores, and its limit.
    Usage(ctx context.Context) (Usage, error)
}
```

Records is the key/value store of one extension, in one namespace. The host sets the namespace, and no argument names it. Every method returns an error that errors.Is matches against the errors of this package.
