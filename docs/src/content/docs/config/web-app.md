The web app is served at the root address of the server. `core.frontend.enabled`
turns it off for a server that only programs talk to. The API stays, and so
does its reference at `/docs`, which every build except the printer build
serves.

The other keys set how the web app looks for everybody: the name, the
language it falls back to, its theme and its style. The name is in the browser
tab, at the top of the sidebar, and on the local network over mDNS. A person
can still change the theme and the style for their own browser, and the
language for their own session.

`core.dashboards.enabled` serves the home page made of cards. Off, the home
page is the list of printers, or the printer's own page when there is only
one. See [Dashboards](../dashboards.md).

The setup wizard sets the name, the language and the theme on its basic path,
and the rest on its advanced one.

### core

Every key has a working default, so a file with no `core:` block starts a server. A key this build does not read is refused at startup, with the line it is written on.

| key | type | default | required | what it does |
|---|---|---|---|---|
| <a id="key-core-frontend-enabled"></a>`core.frontend.enabled` | true or false | `true` | no | Serve the web app at this server's root address. When false, the root address answers 404 and make build does not compile the app. |
| <a id="key-core-frontend-title"></a>`core.frontend.title` | text | `Prusa Connect` | no | The name in the browser tab, at the top of the sidebar and on the local network over mDNS, 64 bytes at most. |
| <a id="key-core-frontend-default-language"></a>`core.frontend.default_language` | text | `en` | no | The language the page falls back to: en, cs, de, es, fr, it or pl. |
| <a id="key-core-frontend-theme"></a>`core.frontend.theme` | text | `system` | no | The palette the page opens in: system, light or dark. system follows the operating system. |
| <a id="key-core-frontend-support-url"></a>`core.frontend.support_url` | text | - | no | Where the app's Support link points. Empty keeps the assistant on the beta portal. |
| <a id="key-core-dashboards-enabled"></a>`core.dashboards.enabled` | true or false | `true` | no | Serve the dashboards the home page draws. Off, the home page is the printer list, or the printer's page when there is one. `make build` leaves them out. |
